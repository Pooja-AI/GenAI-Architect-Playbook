# Why Azure API Management?

## Short answer
API Management is the managed gateway that centralises security, traffic control and versioning in front of CWD.

## Key points
- Token validation, rate limits, quotas and request validation.
- Versioning, transformation, caching, analytics and developer portal.
- Private networking options.
- AI-gateway policies for Azure OpenAI, such as token limits and token metrics.

## CWD context
Clients only ever see APIM, never backend addresses.
