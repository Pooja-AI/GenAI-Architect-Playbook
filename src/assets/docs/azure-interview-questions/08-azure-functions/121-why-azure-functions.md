# Why Azure Functions?

## Short answer
Azure Functions is event-driven serverless compute with rich triggers and bindings, ideal for small, reactive pieces of CWD.

## Key points
- Triggers for Service Bus, Event Grid, Blob, Timer and HTTP.
- Automatic scaling and pay-per-use options.
- Managed identity and Key Vault integration.
- Fast to build glue and webhook code.

## CWD context
Functions handle event glue; long-running, stateful services belong on Container Apps.
