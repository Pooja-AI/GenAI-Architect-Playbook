# Functions vs AKS?

## Short answer
Functions is the simplest option; AKS gives full Kubernetes control at the cost of operations.

## Key points
- Choose AKS for custom networking, operators, GPUs, service mesh or many teams sharing a platform.
- Choose Functions when triggers and short tasks fit and low operations matter.

## CWD context
Start simple, and move to AKS only when a real requirement appears.
