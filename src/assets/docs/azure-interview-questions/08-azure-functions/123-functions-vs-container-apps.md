# Functions vs Container Apps?

## Short answer
Functions run event-triggered code; Container Apps run long-lived containers with full framework freedom.

## Key points
- Functions: trigger and binding model, per-execution billing, limited runtime control.
- Container Apps: any container, HTTP services, KEDA scaling, revisions, Dapr and sidecars.

## CWD context
Orchestrator and MCP servers on Container Apps; event glue on Functions.
