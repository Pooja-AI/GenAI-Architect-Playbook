# Azure AI Search vs Azure AI Foundry/Knowledge-base capabilities?

## Short answer
AI Search is the retrieval engine; Foundry knowledge-base or agentic-retrieval features sit above it and add query planning across knowledge sources.

## Key points
- AI Search gives full control over chunking, ACL filters and ranking.
- Higher-level features can decompose queries and combine multiple sources with less code.
- These features are evolving; verify current capabilities.

## CWD context
Use AI Search directly where security filters and custom chunking matter; evaluate the higher-level option where it reduces work.
