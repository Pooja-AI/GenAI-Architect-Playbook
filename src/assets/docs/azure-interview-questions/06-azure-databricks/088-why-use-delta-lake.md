# Why use Delta Lake?

## Short answer
Use Delta Lake for reliability, safe updates and auditability.

## Key points
- No partial writes or corrupted tables.
- Upserts and deletes for incremental loads and erasure requests.
- Time travel to reproduce past states for audits.
- Performance features such as data skipping and compaction.

## CWD context
Time travel lets you reproduce exactly what data an old answer was based on.
