# What workloads would you run in Databricks?

## Short answer
Run heavy, distributed or repeatable data workloads in Databricks.

## Key points
- Bronze / silver / gold ETL pipelines.
- Document parsing, chunking and bulk embedding.
- Data quality checks, deduplication and enrichment with metadata and ACLs.
- Analytics on telemetry and evaluation results.

## CWD context
Real-time request handling stays out of Databricks; it is for batch and streaming data prep.
