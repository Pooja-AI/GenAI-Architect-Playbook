# How would you monitor Azure AI Search?

## Short answer
Monitor AI Search for latency, throttling and indexer health, plus retrieval quality.

## Key points
- Search latency, queries per second, throttled query percentage, storage.
- Indexer status and failures; operation logs.
- Alerts on throttling and latency; recall and precision from evaluation runs.

## CWD context
Infrastructure health does not prove retrieval quality.
