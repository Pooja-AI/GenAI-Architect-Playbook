# How would you create alerts?

## Short answer
Create alerts for symptoms and causes, with clear ownership and runbooks.

## Key points
- Metric alerts, log-search (KQL) alerts, activity-log alerts and availability tests.
- Action groups to email, Teams, on-call or ITSM.
- Symptoms: latency, error rate, SLO burn. Causes: DLQ, throttling, capacity.
- Severity tiers and noise control.

## CWD context
Every alert should link to a runbook and an owner.
