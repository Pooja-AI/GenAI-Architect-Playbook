# Application Insights vs Azure Monitor?

## Short answer
Azure Monitor is the platform; Application Insights is its application-performance-monitoring feature.

## Key points
- Azure Monitor: metrics, Log Analytics, alerts, workbooks, autoscale.
- Application Insights: requests, dependencies, traces, exceptions, Application Map.
- Workspace-based Application Insights stores its data in Log Analytics.

## CWD context
Both are used together: App Insights for app telemetry, Azure Monitor for the rest.
