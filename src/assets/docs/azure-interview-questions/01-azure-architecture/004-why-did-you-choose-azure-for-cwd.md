# Why did you choose Azure for CWD?

## Short answer
Azure fits an enterprise already on Microsoft: one identity plane, private networking, compliance coverage and enterprise-grade Azure OpenAI.

## Key points
- Identity: Entra ID plus managed identities give one identity model from user to database.
- Azure OpenAI: private endpoints, content filtering, regional or data-zone deployments, and Microsoft states customer prompts are not used to train the base models.
- Integration with M365 / SharePoint, Purview, Defender and Sentinel.
- Trade-off: some platform lock-in, reduced by using open protocols (MCP, A2A), containers and a model-abstraction layer.

## CWD context
Frame it as fit for this enterprise, not as "the best cloud".
