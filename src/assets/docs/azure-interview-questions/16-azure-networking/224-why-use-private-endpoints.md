# Why use private endpoints?

## Short answer
Private endpoints give a service a private IP in your VNet so traffic stays off the public internet.

## Key points
- Public access can be disabled entirely.
- Per-resource control with NSG and routing.
- Reduces data-exfiltration paths; supports compliance.
- Cost and DNS complexity are the trade-offs.

## CWD context
Correct private DNS is the most common stumbling block.
