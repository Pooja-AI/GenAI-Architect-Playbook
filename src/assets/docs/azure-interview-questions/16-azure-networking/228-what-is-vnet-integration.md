# What is VNet integration?

## Short answer
VNet integration lets a PaaS app make outbound calls into a VNet; it is not for inbound private access.

## Key points
- Regional VNet integration uses a delegated subnet (Functions, App Service).
- Container Apps environments can be deployed into your own VNet.
- For inbound private access use a private endpoint.

## CWD context
Outbound integration and inbound private access are two separate features.
