# Why Entra ID for CWD authentication?

## Short answer
Entra ID is the enterprise identity provider that authenticates users and workloads and issues tokens.

## Key points
- SSO, MFA and Conditional Access.
- OIDC / OAuth 2.0 tokens; groups and app roles.
- Managed identities for workloads; integrates with APIM, Azure RBAC and Microsoft 365.

## CWD context
One identity plane from user to database simplifies security and audit.
