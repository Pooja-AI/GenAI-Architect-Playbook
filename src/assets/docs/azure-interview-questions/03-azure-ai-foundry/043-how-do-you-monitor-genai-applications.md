# How do you monitor GenAI applications?

## Short answer
Monitor GenAI apps for quality and safety as well as uptime.

## Key points
- OpenTelemetry traces to Application Insights covering LLM, retrieval and tool calls.
- Token, latency and cost dashboards.
- Continuous evaluation on sampled production traffic; groundedness trends.
- User feedback capture and safety alerts.

## CWD context
A stable error rate can hide a quality regression; quality needs its own metrics.
