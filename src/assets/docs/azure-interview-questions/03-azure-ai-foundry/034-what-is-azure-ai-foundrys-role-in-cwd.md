# What is Azure AI Foundry's role in CWD?

## Short answer
AI Foundry is the control plane for building, evaluating, governing and operating GenAI; it may appear as Microsoft Foundry in newer portals and docs.

## Key points
- Model catalog and deployments, projects with RBAC and connections.
- Evaluations, tracing and safety tooling.
- Optional managed Agent Service.

## CWD context
Foundry handles evaluation, governance and tracing while the LangGraph runtime stays in CWD's own containers.
