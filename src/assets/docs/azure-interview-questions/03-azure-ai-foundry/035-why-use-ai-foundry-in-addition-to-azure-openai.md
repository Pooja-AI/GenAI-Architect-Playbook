# Why use AI Foundry in addition to Azure OpenAI?

## Short answer
Azure OpenAI is the model inference resource; Foundry adds the lifecycle around it.

## Key points
- A broader model catalog beyond OpenAI models.
- Evaluation, tracing, prompt tooling and safety in one place.
- Projects and connections give team-level governance.
- Agent Service if managed agents are wanted.

## CWD context
Use Azure OpenAI for inference and Foundry for evaluation and lifecycle.
