# When would you choose AKS instead of Container Apps?

## Short answer
Choose AKS when Container Apps cannot meet a specific requirement.

## Key points
- Need Kubernetes APIs, CRDs or operators.
- Custom CNI, network policies or service mesh.
- GPU or specialised nodes, multi-cluster, portability.
- Cost or scale efficiency at very large scale; team has Kubernetes skills.

## CWD context
Otherwise stay on Container Apps.
