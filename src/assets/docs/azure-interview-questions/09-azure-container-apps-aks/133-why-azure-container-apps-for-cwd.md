# Why Azure Container Apps for CWD?

## Short answer
Container Apps gives serverless containers with KEDA scaling and revisions without running Kubernetes.

## Key points
- Scale to zero and event-driven scaling rules.
- Revisions with traffic splitting; ingress and VNet integration; managed identity.
- Optional Dapr; jobs for batch work.

## CWD context
A good fit for FastAPI, LangGraph services and MCP servers.
