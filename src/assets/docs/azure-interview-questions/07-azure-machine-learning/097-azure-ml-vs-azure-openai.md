# Azure ML vs Azure OpenAI?

## Short answer
Azure OpenAI serves pre-trained foundation models through an API; Azure ML is the platform for training and deploying your own models.

## Key points
- Azure OpenAI: generative language tasks, no training required.
- Azure ML: any framework, your data, full MLOps lifecycle.

## CWD context
Use each for what it is best at; they complement rather than compete.
