# Why Azure Machine Learning in CWD?

## Short answer
Use Azure ML for custom predictive models that an LLM API is the wrong tool for.

## Key points
- Classification, ranking, anomaly detection and forecasting.
- Small task-specific models with low latency and cost.
- Experiment tracking, model registry, managed endpoints, pipelines and monitoring.

## CWD context
Workers can call Azure ML endpoints for scoring while LLMs handle language tasks.
