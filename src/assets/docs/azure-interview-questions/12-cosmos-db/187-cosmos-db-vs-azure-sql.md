# Cosmos DB vs Azure SQL?

## Short answer
Cosmos DB suits key-based document state; Azure SQL suits relational data and ad-hoc queries.

## Key points
- Cosmos: flexible schema, horizontal scale, low-latency key access, global distribution.
- SQL: joins, complex queries, cross-table transactions, reporting.

## CWD context
Runtime state in Cosmos; reporting and analytics in SQL, Fabric or Databricks.
