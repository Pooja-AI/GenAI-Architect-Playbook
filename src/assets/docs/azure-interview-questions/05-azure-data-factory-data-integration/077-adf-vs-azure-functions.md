# ADF vs Azure Functions?

## Short answer
ADF moves and orchestrates data at scale; Functions run custom code.

## Key points
- ADF: bulk copy, connectors, scheduling, low code.
- Functions: custom parsing, webhooks, small event-driven logic.
- They combine well: ADF can call a Function.

## CWD context
Use ADF for bulk ingestion and Functions for custom crawlers or webhooks.
