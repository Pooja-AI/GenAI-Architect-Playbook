# Why Azure Data Factory?

## Short answer
Azure Data Factory is a managed data-movement and orchestration service with a wide connector set.

## Key points
- Many built-in connectors, including Salesforce, ServiceNow, Oracle and SharePoint.
- Managed VNet integration runtime and private endpoints.
- Scheduling, triggers, monitoring, retries.
- Integrates with Databricks, Functions, Key Vault and Purview.

## CWD context
ADF moves and orchestrates; heavy transformation belongs in Databricks.
