## What is a String?

A **string** is a sequence of characters used to represent **text**.

Characters can include:

* Letters: `A-Z`, `a-z`
* Numbers: `0-9`
* Spaces
* Special characters: `@`, `#`, `$`, `!`, etc.

### Example in Python

```python
name = "Pooja"
```

Here, `"Pooja"` is a **string**.

Another example:

```python
message = "Hello World!"
```

### Key points

* Strings are usually written inside **single quotes `' '`** or **double quotes `" "`**.
* Each character has a position called an **index**.
* Indexing usually starts at **0**.

For example:

```text
P O O J A
0 1 2 3 4
```

So:

```python
name[0]  # P
name[2]  # O
```

**Interview definition:**

> A string is an ordered sequence of characters used to store and manipulate textual data.
