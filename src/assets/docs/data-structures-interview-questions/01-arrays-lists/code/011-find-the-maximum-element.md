## Find the Maximum Element in an Array

Given an array of integers, **find and return the maximum element in the array**.

### Example

**Input:**

```text
[10, 25, 7, 42, 18, 31]
```

**Output:**

```text
42
```

### Requirements

* The array may contain positive and negative integers.
* Do not use Python's built-in `max()` function.
* Return the maximum value.
* Consider the time and space complexity of your solution.
